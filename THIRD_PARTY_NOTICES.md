# Third-party software

The Airflow app bundles these components, each under its own license:

| Component | License |
|---|---|
| [Python](https://www.python.org/) | PSF License |
| [pygame-ce](https://github.com/pygame-community/pygame-ce) and the SDL libraries it includes | LGPL 2.1 (pygame-ce), zlib (SDL) |
| [NumPy](https://numpy.org/) | BSD 3-Clause |
| [certifi](https://github.com/certifi/python-certifi) | MPL 2.0 |
| [PyInstaller](https://pyinstaller.org/) bootloader | GPL 2.0 with the bootloader exception |
| [Inter](https://rsms.me/inter/) font (download page only) | SIL Open Font License 1.1 |

The game uses the system Arial font that ships with macOS. Nothing from DUCTWORKS is included.
Airflow is an original reimplementation of its gameplay ideas.
